# 一码 OneVerifyCode · 设计方向

## 1. 气质

**安静的守门人。** 它不抢注意力：平时只是菜单栏上一个 18px 的极简符号；验证码到来时才短暂出现，默认 8 秒后由底部进度条走完并自动退场。整体语言接近 macOS 原生工具（如“电池”“Wi-Fi”面板），不做拟物、不做彩色大图、不做动效炫技。

三个关键词：

- **克制**：一屏只保留一个主操作（点击验证码填入），没有按钮、关闭键与倒计时文字。
- **确信**：验证码用等宽字体大号显示，一眼可核对；来源与时间用小字灰阶，不干扰主体。
- **即时**：从短信落库到可粘贴 ≤ 3 秒；弹窗出现不动画位移，只做 120ms 淡入。

## 2. 色板

以靛蓝为主色（避免 Material 默认蓝），中性色走系统语义色，保证浅色/深色自动适配。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `accent` | `#3B5BDB` | `#7C8FFF` | 主按钮、选中态、进度条 |
| `accentPressed` | `#2F49AF` | `#6476E6` | 按下态 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 卡片/窗口底 |
| `surfaceAlt` | `#F5F6F8` | `#2C2C2E` | 分组底、输入框 |
| `stroke` | `#E3E5EA` | `#3A3A3C` | 1px 描边 |
| `textPrimary` | `#16181D` | `#F2F2F7` | 标题、验证码 |
| `textSecondary` | `#6B7280` | `#9A9AA0` | 说明、来源 |
| `textTertiary` | `#9CA3AF` | `#6E6E73` | 占位、倒计时 |
| `success` | `#1F9D55` | `#4ADE80` | “监听中”状态点 |
| `warning` | `#B45309` | `#FBBF24` | 权限缺失 |
| `danger` | `#C0392B` | `#FF6B6B` | 错误 |

所有颜色只允许在 `OVCTheme.m` 中定义；其它文件必须调用 `OVCColor(...)` 语义方法，禁止字面量。

## 3. 字阶

| Token | 字号/字重 | 用途 |
| --- | --- | --- |
| `code` | 30 / Semibold，等宽（SF Mono） | 卡片中的验证码，字距 +2.4 |
| `title` | 17 / Semibold | 窗口标题、卡片标题 |
| `body` | 13 / Regular | 正文、菜单 |
| `caption` | 11 / Regular | 来源、时间、倒计时 |
| `mono` | 12 / Medium，等宽 | 历史列表中的验证码 |

行高：正文 1.45；标题 1.25。中文不追加大字距，数字与英文保持系统默认。英文文案沿用同一字阶，侧栏 App 名使用 subhead 字号避免截断。

## 4. 间距与圆角

- 间距阶：4 / 8 / 12 / 16 / 24 / 32（`OVCSpace`）。
- 卡片内边距 16，卡片间距 12，窗口边距 20。
- 圆角：卡片 12、悬浮面板 14–18（随紧凑/标准/宽适）、按钮 8、图标底座 18（连续圆角）。
- 悬浮面板：标准 244×80（紧凑 224×74 / 宽适 276×90），圆角 16，来源小字居中，验证码居中，底部 2.5px 进度条；7 套主题渐变叠加半透明材质；纯白/纯黑为固定明暗极值，文字色不随系统外观反转，背景透明度 0–100% 可调。
- 描边 1px，不用阴影表达层级（弹窗除外，用 24px 模糊、8% 黑）。

## 5. 图标

- **菜单栏**：18×18 模板图（纯 alpha）。造型 = 圆角方框 + 数字“1”（竖笔 + 左上旗 + 底横），框线 1.45，数字线宽 1.3。外框在菜单栏里更易辨识，随系统浅色/深色自动反色。
- **App 图标**：1024 画布，石墨渐变（`#0E1218 → #232B36`）连续圆角方块，中央暖白“1”，右下角薄荷色圆形认证徽章（内含深色对勾），内描边 1px 白 14%。极简，无文字、无投影堆叠。
- 生成方式：`tools/icongen.m` 用 Core Graphics 绘制，`iconutil` 合成 `.icns`；仓库内保留 1024 PNG 预览。

## 6. 动效

| 场景 | 时长 | 曲线 | 说明 |
| --- | --- | --- | --- |
| 弹窗出现 | 120ms | ease-out | 透明度 0→1，位移 0（避免“跳脸”） |
| 弹窗消失 | 160ms | ease-in | 透明度 1→0 |
| 悬停按钮 | 90ms | linear | 背景色变化 |
| 关闭进度 | 线性 | linear | 底部横条随停留时长缩短，结束后淡出 |
| 减少动态（系统开启） | 0ms | — | 直接显隐，不做淡入 |

语言切换位于设置侧栏底部，使用原生弹出菜单；切换后设置页原地重建，保留当前 section。
设置窗口只在左侧侧栏拖动：右侧内容区禁止背景拖动；左侧品牌头部与空白区域使用透明拖拽层。关于页底部使用 14pt GitHub mark + accent 色仓库地址，整行可点击。
权限卡操作按钮固定 28pt 高、最小宽度 120pt，按文案宽度收缩；强调态使用 accent 填充，已授权态改为 12pt 勾选 + 次要文案，避免满宽禁用按钮。

## 7. 四态

| 状态 | 菜单栏 | 主窗口 |
| --- | --- | --- |
| 加载 | 图标不闪，菜单首行“正在启动…” | 骨架：卡片占位灰块 |
| 空 | “等待新验证码” | 历史区：“还没有记录，来一条短信试试”+“扫描最近 24 小时”按钮 |
| 错误 | 图标形状不变，菜单首行红点 + 原因 | 顶部横幅：“无法读取短信：需要完全磁盘访问”，带“去授权” |
| 无权限/不可用 | 首行“需要授权” + 跳转项 | 权限卡两行状态，缺失项红点 |

## 8. 无障碍

- 验证码数字热区外扩到约 264×60 pt，远大于 44×44；无其它按钮。
- 对比度：正文 ≥ 7:1，次要文字 ≥ 4.5:1；深色模式单独校验（`#9A9AA0` on `#1C1C1E` ≈ 6.4:1）。
- 键盘可达：菜单项均有等价入口（菜单本身支持方向键与回车）；弹窗仅保留点击数字填入，避免键盘焦点抢占。
- VoiceOver：验证码整体作为一个 `accessibilityLabel`（“验证码 1 2 3 4 5 6”逐位朗读），按钮有明确 label。
- 不依赖颜色单独传达状态：状态点旁始终有文字。
- 尊重“降低透明度”与“增强对比度”系统开关：开启后卡片背景改为不透明纯色、描边加深。

## 9. 文案

| 位置 | 文案 |
| --- | --- |
| 菜单首行 | 监听中 · 今日 3 条（关闭时为灰色“监听已关闭”） |
| 菜单项 | 监听 / 最近验证码 / 设置… / 退出一码 |
| 弹窗标题 | 短信验证码（副标题为“短信 · 发送方脱敏”） |
| 弹窗按钮 | 粘贴 / 复制 / 关闭（后续版本按反馈精简） |
| 权限提示 | 需要“完全磁盘访问”才能读取短信 / 需要“辅助功能”才能定位输入框与自动粘贴 |
| 空历史 | 还没有记录。收到验证码短信后会自动出现在这里。 |

语气：陈述句、无感叹号、不卖萌、不解释技术细节（技术说明放设置页折叠区）。
