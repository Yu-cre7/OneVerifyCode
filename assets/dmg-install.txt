一码 OneVerifyCode
================

拖拽安装
--------
1. 将左侧的“一码.app”拖到右侧的“Applications”文件夹。
2. 打开“应用程序”中的“一码”。
3. 首次启动请按提示授予“完全磁盘访问”；需要点击填入时再授予“辅助功能”。

如果 macOS 提示无法验证开发者，请右键“一码.app” → “打开”，
或在终端执行：
xattr -dr com.apple.quarantine "/Applications/一码.app"

Drag to install
---------------
1. Drag “一码.app” on the left onto the Applications folder on the right.
2. Open “一码” from Applications.
3. Grant Full Disk Access when prompted. Grant Accessibility only if you want click-to-fill.

If macOS cannot verify the developer, right-click the app and choose Open,
or run:
xattr -dr com.apple.quarantine "/Applications/一码.app"
